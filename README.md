# NA Events 3.0.0 — Multi-événements

Ce pack transforme la partie publique en portail d'inscriptions multi-événements.

## Parcours public

1. Liste des événements visibles.
2. Détail d'un événement.
3. Choix d'une session.
4. Réservation ou liste d'attente.

## Statuts d'événement

- `draft` : brouillon, invisible
- `published` : visible et réservable
- `full` : visible, liste d'attente
- `closed` : invisible et non réservable
- `archived` : conservé uniquement dans l'administration

## Compatibilité

Le pack conserve :
- les sessions
- les réservations
- les listes d'attente
- les présences
- les PDF
- les exports Excel
- la duplication
- l'état global des inscriptions
